# Proget

Application web pour permettre un inventaire participatif d'éléments de patrimoine, utilisé entre autre pour un inventaire nécessaire pour les annexes du Plan Local d'Urbanisme Intercommunal (PLUi)

Utilisateurs :
 - Habitants
 - Agents
 - Elus
 - Cabinet de conseil


Technologies :
 - python
 - django
 - Postgresql
 - Boostrap


 Exigences :
 - Gestion documentaire
 - Tests unitaires
 - Respect du RGPD
 

Application de Cartograhie :
 - OpenStreetMap
 

Arborescence :
 - ./app : Dossier du projet django
 - ./.env : Fichier de variables d'environnement
 - ./app/element : Dossier de l'app django pour la saisie de l'inventaire
